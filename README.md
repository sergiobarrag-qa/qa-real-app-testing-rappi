# QA Testing – Rappi App (Flujo de Compra)

## 📌 ¿Qué es este proyecto?

Proyecto de testing manual enfocado en la validación de un flujo crítico de usuario dentro de la aplicación Rappi.

## 🎯 Objetivo

Evaluar la funcionalidad del proceso de búsqueda, selección y gestión de productos en el carrito, identificando errores y riesgos en la experiencia del usuario.

## 🔍 Alcance

Incluye:
- Búsqueda de productos
- Agregado al carrito
- Validación de precios y cantidades

No incluye:
- Login
- Pago

## 🧪 Artefactos

- Casos de prueba estructurados
- Reporte de bugs
- Checklist de validación

## 🧠 Decisiones QA

- Se priorizó el flujo de compra por ser el más crítico del negocio
- Se evaluaron escenarios positivos y negativos
- Se incluyeron pruebas de comportamiento bajo interacción rápida

## 📊 Resultados

- Se identificaron inconsistencias en la gestión del carrito
- Se detectaron fallos potenciales en la experiencia de usuario
- Se evidenciaron riesgos en validaciones de producto

## 🚀 Mejora futura

- Incluir pruebas de login y pagos
- Automatización de casos críticos
